確認日：2026-09-26（日本時間）。根拠は同梱note.docの「●使用方法」です。全15種類のスイッチと併記を再確認しました。実装・自動検査はLinux/GCCで実施し、改訂3でも38項目が成功しました（rev3_legacy_cli_results.txt）。提供された改訂2のWindowsログではMSVCビルドとlegacy_cliテストが成功しています。改訂3のWindows再実行、実際のビープ音、元note.xの画面との完全一致は未確認です。

## -oの互換用別名

元の-oは-lと組み合わせるPCM使用マップの論理和指定です。以前のNoteMDXが別用途の-o FILEを導入していたため、改訂1では出力先の明示指定に--output FILEを追加しました。

```text
notemdx.exe -iBH -v1 -w song.mus
notemdx.exe -lo song.mus
notemdx.exe --output result.mdx song.mus
```

-o FILEの互換用別名は「既に入力名が指定されている」「次のファイル名が.mdx/.MDX」「出力名と入力名が連続する」のいずれかで認識します。その他は原版の引数なし-oです。曖昧な組合せを避けるため、MDXの出力先は--output、PCMマップ指定は-loとしてください。

## 対応範囲と制限

- PCM使用マップ：利用できる仕様・参照ファイルがないため、以前の合意どおり対象外です。原版の表現を受理しますが、ファイル生成ができたとは表示しません。
- 大容量MDX：改訂2でファイル全体の64KiB超に対応。今回の原版出力で通常形式の音色データ末尾が境界を越えることを確認しました。トラック位置超過と長距離ループは原版も拒否したため、無制限には拡張しません。
- エラー後の解析継続：-eの登録済みバンク保存は実装しましたが、誤った構文からの復帰規則が未確定のため、最初の致命的エラーで止めます。
- #remove/#beep/#ver：この版では疑似命令側は警告して無視します。対応するCLIスイッチを使用してください。#playも実行しません。

## 表示

```text
Title       : Example
FM voices   : 0, 1, 2, 4, 10, 11
PCM bank0   : 0-3, 8
PCM bank255 : 95
OPM track   :      A      B      C      D      E      F      G      H
Total steps :    192    192      0      0      0      0      0      0
Loop steps  :    144      -      -      -      -      -      -      -
```

項目は11文字に右を空白で埋め、その後に半角空白1つと:を置きます。FM音色は全番号を個別表示し、FM/PCMの未使用番号は表示しません。APIの未使用番号フィールドは互換性のため維持します。
